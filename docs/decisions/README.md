# Decision records

One short file per big choice, so nobody has to rediscover why. Number files in order (`NNNN-short-title.md`) and use this shape:

- **Status:** Proposed, Accepted or Superseded by NNNN
- **Context:** the problem and what we knew
- **Decision:** what we chose
- **Consequences:** what gets easier, what gets harder

Change a decision by adding a new record that supersedes the old one; do not rewrite history.
